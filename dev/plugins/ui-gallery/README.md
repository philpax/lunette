# UI gallery

The gallery shows the standard kinds of the UI toolkit on one panel, grouped into pages: display, actions, choices, values, collections, structure, and Markdown. The header row switches the theme between dark and light and changes the accent colour. The development configuration loads it closed; the Widget gallery action in the wrist menu's Development group opens and closes it, and the header's close button closes it. It also contributes a settings page with the theme mode to the plugin manager's settings outlet, which the manager's Configure tab shows when the gallery is selected.

[pages.luau](pages.luau) holds the pages as components, so the offscreen graphics suite renders the same content into PNG snapshots for review.
