# Workspaces

Shows one configured workspace by hiding panels tagged for other workspaces. Untagged windows join the selected workspace. With `follow` enabled, new windows assigned only to other workspaces move to the selected one.

The entry never reveals panels hidden by another plugin. A menu outage leaves workspace visibility and selection unchanged.
