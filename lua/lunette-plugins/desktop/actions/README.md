# Session actions

Registers Reload configuration in the wrist menu. The optional Keyboard child registers the keyboard toggle separately, so a keyboard-display outage does not disable reload.

| Requires | Optional |
| --- | --- |
| `lunette/menu` | `lunette/keyboard-display` for the Keyboard child |

See [Wrist menu](../../../../docs/guide/desktop-configuration.md#wrist-menu) and the [menu action contract](../../../../docs/dev/lua-api.md#bindings-menu-actions-and-layouts).
