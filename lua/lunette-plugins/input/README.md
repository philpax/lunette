# Input

Input separates physical-key delivery, focus authority, virtual keyboards, keyboard display, and controller attachment. [Bindings](bindings/README.md) matches host chords before physical delivery. [Focus](focus/README.md) routes keys to native sinks or local receivers, and [physical routing](physical-routing/README.md) delivers physical keys and committed text to the focused target. [Keyboard](keyboard/README.md) creates caller-owned boards to place, offer, and draw; [keyboard display](keyboard-display/README.md) manages shared-board visibility. [Laser](laser/README.md) attaches controller input to interaction pointers and draws feedback; [hand pointers](hand-pointers/README.md) attaches both hands to it.

The [bindings](../../lunette-contracts/bindings.luau), [focus](../../lunette-contracts/focus.luau), [keyboard](../../lunette-contracts/keyboard.luau), [keyboard-display](../../lunette-contracts/keyboard-display.luau), and [laser](../../lunette-contracts/laser.luau) contracts define services. The [input protocol](../../lunette-contracts/docs/input.md) defines delivery and cancellation. Spatial pointer policy belongs to [interaction](../interaction/README.md).

The keyboard publishes [hook types](keyboard/hooks.luau) at `@lunette-plugins/input/keyboard/hooks` for keys and state supplied to configured press and draw callbacks, and [legend drawing](keyboard/legend.luau) at `@lunette-plugins/input/keyboard/legend`. Legend drawing uses the draw hook's supplied pass and font, restores pass state, and acquires no retained resources. Neither extension publishes services or exposes the keyboard renderer. [Shipped plugins](../README.md) defines public imports.
