# Session actions

Adds Reload configuration and the optional Keyboard and Hide panels actions to the wrist menu. Hide panels hides every window and monitor panel, every toolkit panel except essential ones such as the wrist menu, and the keyboard, including panels that open while it is on, until it is chosen again. A panel that another plugin hid stays hidden, and the keyboard returns where it was, if it was up. Hide panels stays on across a reload or restart. A keyboard-display or panel-registry outage does not disable reload.
