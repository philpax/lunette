# Session actions

Adds Reload configuration and the optional Keyboard and Hide panels actions to the wrist menu. Hide panels hides every window and monitor panel, including panels that open while it is on, until it is chosen again; a panel that another plugin hid stays hidden. A keyboard-display or panel-registry outage does not disable reload.
