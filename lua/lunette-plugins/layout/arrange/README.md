# Window arrangement

Arranges windows without poses by tag using a named layout. Saved poses and windows dropped during this activation stay untouched; a drop does not move neighbouring panels.

Selected tags take priority, then configuration order. An empty tag list includes all tags and untagged windows; a configured list leaves other windows alone.
