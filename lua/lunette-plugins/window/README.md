# Window

Window separates property resolution, rule sources, placement, and adoption. [Rule resolver](rule-resolver/README.md) resolves properties from ordered sources; [configured rules](configured-rules/README.md) registers shipped rules or a replacement list independently of resolution. [Placement](placement/README.md) creates panels and tag memberships without adopting windows itself. [Adoption](adoption/README.md) connects eligible compositor windows to placement; [adoption controller](adoption-controller/README.md) supplies default tags, filtering, and optional pose memory.

The [rules](../../lunette-contracts/rules.luau), [placement](../../lunette-contracts/placement.luau), and [adoption](../../lunette-contracts/adoption.luau) contracts define services. The neutral [rules schema](../../lunette-contracts/schemas/rules.luau) owns value validation and field classification. [Policy guarantees](../../lunette-contracts/policy-services.md) and [placement precedence](../../../docs/development/standard-plugins.md#placement) define source ordering and initial adoption. [Shipped plugins](../README.md) defines public imports.
