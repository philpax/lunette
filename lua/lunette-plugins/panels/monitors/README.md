# Monitor mirrors

Mirrors selected host monitors; an empty selection includes every monitor. New mirrors take free row positions without moving existing mirrors. The wrist menu's Monitors group has an action for each monitor that mirrors it or closes its mirror. A mirror closed there or from its titlebar is saved in `hidden`, so it stays closed at the next start until the action reopens it; a monitor that is unplugged is not hidden. Tagging and menu outages leave mirroring active.
