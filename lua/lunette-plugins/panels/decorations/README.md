# Panel titlebars

Adds a titlebar to each window and monitor panel, including panels with native chrome. The titlebar is a toolkit panel attached above its panel: it takes the panel's width, follows it, and moves it when grabbed with the grip, or with the trigger on the bar outside its buttons. It shows the title, a close button, the standard Settings control, and, for a monitor mirror, buttons that restart the mirror and select monitors. The Settings control targets the native panel: while a lock is active, its quick unlock flanks the gear, and the popup carries the bend, axis, and both lock toggles. A window or monitor takes a signed bend and a full axis, so the axis row is enabled and a bend away from the viewer is offered. The controller reports the panel's stored curve and axis separately from the clamped bend it displays, so opening and closing the popup without committing restores exactly what was stored, including a curve above the half-turn limit. The old Lock input action is gone. The input lock leaves the titlebar and Settings usable; the transform lock stops the titlebar drag but not its buttons. The titlebar follows its target's curve and axis without writing properties, and the joined outline detaches when the target curves, because that outline is a flat-panel feature. The titlebar's attached placement still comes from the target's pose and dimensions, so its alignment on a strongly tilted target is approximate.

Window close requests application closure; monitor removal stops a mirror without unplugging the host monitor. Client-drawn titlebars can coexist but cannot move the panel in space.

Titlebars take their colours and type from the toolkit theme, which the `ui-host` settings choose; the `height` option sets their height. The previous titlebar style options were removed with the previous toolkit.
