# Standard kinds

Registers the standard kinds and their visuals in the default lunette theme, registers the bundled IBM Plex Sans and Iosevka faces, and publishes the constructors through `lunette/ui-components`. [Theming](../../../../docs/development/ui/theming.md#the-default-theme) describes the theme, and the [widget gallery](../../../../dev/plugins/ui-gallery/README.md) shows every kind.

Lengths that take a spacing token, such as `gap = 'md'`, also take metres. Text takes a type role (`body`, `label`, `caption`, `section`, `heading`, `title`, `value`, `mono`) and a colour role. Choice and collection kinds take options or items with string ids, which they key with `uiHost.keyOf`, so ids may contain any characters. A control with `disabled = true` or `disabledReason` takes no input and is skipped by controller traversal. `disabledReason` also shows the reason. `Outlet` places one of the host's outlets, whose contributions other plugins render; it registers no kind of its own.

A `Button` takes an `icon` and an `active` state. The icon draws in the button's ink in place of the label, and the label stays the accessible name. Active keeps the variant's fill, tints the ink with the accent, lifts the control, and reports `selected` semantics. A `Slider` with `showHeading = false` omits its label row and detent names for a heading held beside a numeric entry; the label remains the accessible name. An `Angle` is a signed angle in degrees on a dial. Its `snap` is the granularity the value always rounds to, and a drag pulses as it reaches each snap angle; `showHeading = false` omits its label row the same way.

A titled `Panel` shows a Settings control left of close and after any caller `HeaderActions`: a gear, and while a lock is active, a quick unlock icon for it. The input lock's quick icon pairs a pointer with a lock, and the transform lock's pairs a move gizmo with a lock. The popup holds the bend and axis, each with a numeric entry and an angle dial that snaps to 22.5 degrees, and both lock toggles; the bend is the surface turn from the centre line to the edge, so 180 is a half turn each side; with no quick icon while unlocked, the popup is the way to enable a lock. A native titlebar supplies a controller that offers the signed bend and full axis; without one the control writes the panel that holds the header. `propertiesControl = false` omits the control. A preview applies while a control is held, and a release or a valid entry commits, so only a committed value reaches the properties store. The popup is parented to the panel: it moves and turns with it, but a bend in the panel's surface does not turn it, so a drag keeps its control.
