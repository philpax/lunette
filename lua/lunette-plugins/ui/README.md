# UI

The UI category provides in-session interfaces. The [UI host](host/README.md) provides panels, kinds, layout, routing, focus, motion, and drawing. The [theme](theme/README.md) resolves the session's palette, which the host and the surfaces drawn outside the toolkit share. The [standard kinds](standard/README.md) provide the controls in the default theme. The [React-like library](react/README.md), `@lunette-plugins/ui/react`, renders components onto host panels. [Notifications](notifications/config.luau) show toasts with a history, [accessibility](accessibility/config.luau) stores the accessibility settings and applies them to the host, and [accessibility settings](accessibility-settings/init.luau) adds a wrist-menu panel that edits them. Larger interfaces remain Wayland clients.

The [host contract](../../lunette-contracts/ui-host.luau), the [theme contract](../../lunette-contracts/theme.luau), and the [component contract](../../lunette-contracts/ui-components.luau) define the services; [panel and UI guarantees](../../lunette-contracts/panels-and-ui.md#ui-host) define coordinates, capture, and ownership. [Focus](../../lunette-contracts/focus.luau) and [surfaces](../../lunette-contracts/surfaces.luau) define input integration. [UI authoring](../../../docs/plugins/ui.md) records composition examples. [Shipped plugins](../README.md) defines public imports.
